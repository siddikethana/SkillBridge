
# 🎓 SkillBridge – Student Skill Matcher

## About the Project
SkillBridge is a student skill matching web application
that helps students discover suitable projects,
learning paths, and internship ideas based on their
skills and interests.

## Problem Statement
Many students find it difficult to identify suitable
career paths and learning opportunities based on
their existing skills.

## Solution
SkillBridge provides personalized suggestions for
projects, learning paths, and internship ideas
based on students' skills and interests.

## Features
- Student name and skills input
- Interest-based recommendations
- Project suggestions
- Learning path suggestions
- Internship ideas
- Responsive website design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open index.html in your browser.
3. Enter your name and skills.
4. Select your interest.
5. Click Find My Matches.
